THE IDEA

What is Linear Regression?

Linear Regression is a supervised machine learning algorithm mainly used to predict a continuous numerical value. It finds a relationship between an independent variable X and a dependent variable Y.

01

Collect Data

Start with observed X and Y values.

02

Fit a Line

Find the line that is closest to the data overall.

03

Predict

Use the fitted equation for a new X value.

04

Evaluate

Use error such as Mean Squared Error (MSE).

Residuals

A residual is Actual − Predicted. It represents the vertical difference between a data point and the regression line.

KEY TAKEAWAYS

Simple, fast, interpretable.

Linear regression works well when the relationship between variables is approximately linear and provides an easy-to-understand baseline model.

✓ Simple and easy to understand
✓ Fast and computationally efficient
✓ Highly interpretable
✓ Useful as a baseline model
! Sensitive to outliers
! Can perform poorly for strong nonlinear relationships
