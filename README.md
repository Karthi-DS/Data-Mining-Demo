# Linear Regression Playground

A simple, fully static website for demonstrating Linear Regression.

## Files

- `index.html` — page structure and content
- `style.css` — responsive design
- `script.js` — regression calculation, MSE, prediction, residuals and canvas graph

## Run locally

Just double-click `index.html`, or open it in any modern browser.

No server, database, Node.js, Python, or API is required.

## Deploy

Upload the three files to any static hosting service or web server.

Examples:
- GitHub Pages
- Netlify
- Vercel static deployment
- Any Apache/Nginx web server

Keep all three files in the same folder.

## Demo flow

1. Explain X and Y.
2. Show the sample Hours Studied → Exam Score data.
3. Click "Calculate Regression".
4. Explain the blue points and orange best-fit line.
5. Show the equation, slope, intercept and MSE.
6. Enter a new X value such as 6 and click "Predict Score".
7. Change one of the data values and show how the model changes.
8. Use the residual table to explain Actual − Predicted.
